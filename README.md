# 🍳 Sous — Multimodal Kitchen Agent

Sous is a multimodal AI kitchen assistant that understands
text, audio and images to help users create recipes.

## Features

- Text instructions
- Audio instructions
- Fridge image analysis
- Ingredient detection
- Recipe web search
- Prompt injection protection
- Task decomposition
- Prompt templates
- Multimodal AI

## Architecture

User
↓
Multimodal Analyzer
↓
Ingredient Agent
↓
Search Agent
↓
Security Agent
↓
Recipe Planner
↓
Final Recipe

## Technologies

- Python
- Streamlit
- Gemini API
- Web Search
- GitHub

## Prompt Engineering

- Prompt templating
- Few-shot examples
- Role prompting
- Structured output
- Decomposition

## Security

External web pages are treated as untrusted data.
Instructions from websites cannot override the agent's
system instructions.
